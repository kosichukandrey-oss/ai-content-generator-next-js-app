# ContentAI Generator

Современное веб-приложение на Next.js для создания контента с помощью бесплатного поиска DuckDuckGo Instant Answer API. Пользователь выбирает формат и стиль текста, описывает тему — и получает готовый результат с возможностью копирования.

## Возможности

- Шесть форматов: Instagram-пост, Stories, Telegram-пост, реклама, описание товара и идея контент-плана.
- Четыре стиля: продающий, экспертный, дружелюбный и премиальный.
- Язык результата: русский, украинский или английский.
- Валидация пустой темы, понятные ошибки API и индикатор генерации.
- Адаптивный современный интерфейс для телефона, планшета и компьютера.
- Отдельный серверный маршрут `POST /api/generate`: получает справочную информацию из бесплатного поиска и создаёт контент без ключей и оплаты.

## Локальный запуск

1. Установите Node.js 20.9 или новее.
2. В корне проекта выполните `pnpm install` (или `npm install`, если используете npm).
3. Запустите приложение: `pnpm dev` (или `npm run dev`).
4. Откройте `http://localhost:3000`.

Ключи, регистрация и банковская карта не нужны. Для справочной информации используется DuckDuckGo Instant Answer API.

## Публикация на Vercel

1. Загрузите репозиторий в GitHub.
2. В [Vercel](https://vercel.com/new) импортируйте репозиторий. Framework Preset будет определён автоматически как Next.js.
3. Нажмите **Deploy**. Vercel установит зависимости и выполнит `npm run build` автоматически.

Переменные окружения для этой версии не требуются.
